Openup original-iPhone RAM helper

The new helper and build recipe are distributed under Openup's MIT license;
the derived USB/bootstrap sequence retains the original BSD-3-Clause terms.
The IOAESAccelerator interface and key835 derivation are documented by the
iPhone Data Protection Tools project, Jean-Baptiste Bedrune and Jean Sigwald:
https://github.com/nabla-c0d3/iphone-dataprotection/tree/572dd5cd8c07f5f14f7ea9488041031dd22a26bb
See ramdisk_tools/IOAESAccelerator.c and the project's BSD-3-Clause notice in
../iphone-dataprotection/NOTICE.txt and licenses/BSD-3-Clause.txt.
The older 72-byte IOAES request ABI is also documented in planetbeing/xpwn's
crypto/aes.c. The helper implements only a fixed device-key query; it does not
contain xpwn's command-line tool, filesystem operations or cryptographic code.

The build uses the unchanged Apple open-source IOKit/libkern headers preserved
under ../iphone-dataprotection/include. Their APSL-2.0 license and provenance
remain in that directory's licenses/ and PROVENANCE.json. The separately obtained
Apple SDK, firmware and runtime libraries are build/validation inputs only and
are not redistributed. The legacy linker and its host-page-size patch are the
same pinned build tools documented in ../iphone-dataprotection/BUILD.txt.

The original-iPhone boot-interface research also consulted the user's public
MIT-licensed iPhone2Gkit at revision 4e23a7434e8bc5e1d8f9a95bd1c8248a2c2bbc75:
https://github.com/channelramble/iPhone2Gkit
Openup uses the pinned Legacy-iOS-Kit 3.1.3 SSH RAM disk instead of importing
that kit's OS 1.0 one-shot installer, activation or filesystem-repair workflows.

This helper is built for the 3.1.3/7E18 RAM disk, regardless of the installed
OS. It requires hw.machine=iPhone1,1, hw.model=m68ap, and an HFS RAM root whose
device number matches /dev/md0. It performs no NAND writes or mounts, repairs,
kernel patches, passcode attempts, or activation changes. --identity
prints only the fixed hardware tuple. --key835 prints the fixed derivation's
16-byte result to its SSH caller, which never logs that key. --bootstrap updates
only the verified RAM root to writable, configures volatile watchdog/loopback/USB
services, and keeps its USB-owning process alive while a child runs foreground
SSHD. It uses a private random per-boot RAM serial rather than exposing a device
identifier. USB setup is bounded to 45 seconds. The replacement rc.boot never
starts the stock restore services, mount.sh, filesystem repair or NVRAM commands.

This initial implementation is experimental: offline validation is not physical
iPhone 2G recovery proof. Installed OS 1.x and 2.0/2.1 are not supported.
